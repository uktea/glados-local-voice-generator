# 検証範囲

Windows 11 / Python 3.12のCPU環境で、モデル導入済みのローカル実装に対する自動テスト18件を確認しています。モデル未導入のチェックアウトでは、実モデルを使用する2件がskipされます。

## 確認済み

- 英語・日本語のWAV生成、英語未知語、CPUフォールバック。
- 推論時にsocket接続を禁止した英語・日本語の実モデルテスト。
- JSON辞書の検証、最長一致、制限付きpickle変換。
- 調波信号を使ったピッチ加工とピーク制限。
- 英語・日本語の引用符、`′`・`″`、行ごとの変換プレビュー。
- 稼働中のGradio APIを介した英語2行・日本語2行のWAV/ZIP生成。
- 長い日本語擬似スペルの自動分割と文字欠落がないこと。
- YMM4用ワーカーの連続リクエスト、モデル再利用、エラー後の応答復旧、`.tmp`へのPCM WAV出力。
- YMM4 Lite 4.56.1.0/.NET 10の参照DLLを用いたプラグインのビルド（警告0・エラー0）。
- C#公開音声生成インターフェースからPython経由の英語・日本語WAV生成。
- 実YMM4の通常ボイスアイテムで日本語を生成し、ホスト側のWAV読込を確認。
- 「私は花が好きです。今日は学校へ行きます。」に対する読み「わたしわ／はなが…がっこうえ」。

## 未確認・既知の制約

- CUDAでの実推論と性能。標準依存関係はCPU版です。
- 別のクリーンなWindows端末でセットアップを最初から完了する試験。
- YMM4の別バージョン、長時間・大量の台本生成。
- 本物や元サイトとの聴感上の完全一致、日本語の自然さ。
- 数字と助数詞の自動変換。YMM4側で`COUNTER`の文字が発音へ混ざる例があります。
- YMM4アクセント指定の完全再現、音素単位の正確な口パク。
- モデル重み・学習音声の再配布・商用利用条件の確定。

比較音声や開発端末固有のログ・設定は公開物に含めていません。
